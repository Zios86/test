# Умный файловый организатор

Настольная программа для Windows, которая наводит порядок в файлах и папках — **безопасно**.

> Сначала понять беспорядок → затем предложить порядок → показать пользователю все изменения →
> только после подтверждения применить их → сохранить возможность отката.

Программа ничего не удаляет, не перемещает и не переименовывает без экрана **«Будет выполнено»** и вашего подтверждения.
При первом запуске включён режим **«Только посмотреть»**: файловая система не меняется вообще.

---

## Возможности

| Раздел | Что делает |
|---|---|
| **Главная** | Выбор папки, «Анализировать», «Навести порядок», режимы, большие карточки: хранилище, дубликаты, старые файлы, временные файлы, неорганизованные, потенциально избыточные данные |
| **Структура** | Дерево «как сейчас» и «как будет» с цветами: переместить / переименовать / объединить / удалить после подтверждения / создать / оставить |
| **Будет выполнено** | Сводка (перемещено, переименовано, создано папок, удалено пустых, в папку восстановления), разделы с флажками у каждого действия, причина и уверенность, разрешение конфликтов имён, «Применить» |
| **Дубликаты** | Точные копии (размер → быстрый хеш → SHA‑256), рекомендуемый экземпляр с объяснением, кнопки «оставить все / новый / старый / отмеченные / в «Дубликаты»»; похожие версии документов (не дубликаты) со сравнением |
| **Что занимает место** | Топ‑100 файлов, корзины >100 МБ…>10 ГБ, диаграмма по типам и по папкам |
| **Давно не использовались** | Фильтры 6 мес / 1 / 2 / 3 года / свой период, перенос в архив (не «мусор»!) |
| **Пустые папки** | Пустые, только со служебными файлами, цепочки пустых каталогов |
| **Названия** | «Новый документ (17).docx», «123.pdf», «IMG_5678.jpg», «final_final2_new.docx»… → понятное имя; массовое переименование по шаблонам с предпросмотром «Было → Станет» |
| **Похожие папки** | «Отчеты», «Отчёты», «Отчеты новые», «Старые отчеты» → объединение с проверкой конфликтов |
| **Возможно лежат не там** | Например, договор в папке с фото отпуска |
| **Временные файлы** | .tmp, недокачанные загрузки, старые установщики, уже распакованные архивы, повторные загрузки |
| **Проекты** | Документы/таблицы/презентации одного проекта → «Проекты/Проект_X/{Документы, Данные, Презентации, Материалы, Архив}» |
| **Поиск** | Имя/маска, расширение, тип, размер, дата, папка, текст внутри документов, виртуальные теги |
| **История** | Журнал всех операций, «Отменить», «Отменить последнее действие», «Восстановить состояние до…», «Удалить окончательно» (только отдельно и после предупреждений) |
| **Настройки** | Режим «Только посмотреть», тема (светлая/тёмная/как в Windows), профили, визуальный конструктор правил «ЕСЛИ … ТО …», исключения, таблица типов файлов, папки «Разобрать» (Inbox), умный анализ содержимого и ИИ |

Режимы: **Быстрая уборка** (дубли, пустые папки, старые установщики, крупные файлы), **Умная сортировка**,
**Глубокий анализ** (текст документов, затем — при необходимости — ИИ), **Ручной режим** (только ваши правила).

Каждое предложение **объяснимо** и имеет **уровень уверенности**:

```
☑ Переместить  KP_Rostelecom.pdf → Работа/Коммерческие предложения/KP_Rostelecom.pdf   [95%]
  Причина: название содержит ключевые слова темы «Коммерческие предложения» (КП, …); тип файла: Документы (PDF);
           в этой папке обнаружены ещё 2 файл(а) этой темы.
☐ Переместить  Счет_45.pdf → Финансы/Счета/Счет_45.pdf   [80% — средняя: решите сами]
```

Автоматически отмечаются только предложения с высокой уверенностью (по умолчанию ≥ 85 %).

## Безопасность

* Ничего не удаляется автоматически. «Удаление» = перемещение в `FileOrganizer_Recovery` (или в Корзину Windows — по выбору).
  Безвозвратно — только командой «Удалить окончательно» в «Истории» после двух предупреждений.
* Существующие файлы **никогда не перезаписываются**: при конфликте — «оставить оба (с номером)», «пропустить» или
  «заменить» (старый файл уходит в папку восстановления — тоже обратимо). Конфликт проверяется и при планировании, и прямо перед выполнением.
* Каждая операция журналируется **до** выполнения и **после** — после сбоя программа сверяет журнал с диском.
* Системные каталоги (Windows, Program Files, ProgramData, AppData, $Recycle.Bin…) не сканируются и не изменяются; файлы с атрибутом «Системный» не трогаются.
* Содержимое документов не хранится и не пишется в журнал. ИИ по умолчанию выключен; используется локальная модель (Ollama);
  отправка фрагментов во внешний сервис — только с отдельного согласия. ИИ получает лишь имя файла и короткий фрагмент текста.

## Быстрый старт

1. Скачайте `FileOrganizer.exe` (сборка `FileOrganizer-win-x64` — один файл, установка .NET не нужна) и запустите.
2. «Выбрать папку» → «Анализировать» (или «Навести порядок»).
3. Посмотрите «Структуру» и «Будет выполнено», снимите лишние флажки.
4. Отключите режим «Только посмотреть» (внизу слева) и нажмите «Применить».
5. Передумали — «История» → «Отменить».

Данные программы: `%LOCALAPPDATA%\FileOrganizer` (база SQLite и журналы). Можно переопределить переменной `FILEORGANIZER_DATA`.

## Консольная версия

```
fo analyze  "C:\Users\me\Downloads"
fo plan     "C:\Users\me\Downloads" --strategy smart --dups --empty     # только предпросмотр
fo apply    "C:\Users\me\Downloads" --strategy type                      # спросит подтверждение
fo history
fo undo                     # отменить последнее действие
fo restore --before "2026-10-12 21:00"
fo purge 3 --yes            # окончательно удалить файлы пакета №3 из папки восстановления
```

## Сборка

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```powershell
# Windows
.\build\build.ps1
```

```bash
# Linux/macOS (WPF собирается для Windows через EnableWindowsTargeting)
./build/build.sh
```

Результат в `artifacts/`:

* `FileOrganizer-win-x64/FileOrganizer.exe` — один файл, не требует установленного .NET (~70 МБ);
* `FileOrganizer-win-x64-fx/FileOrganizer.exe` — компактная версия (~8 МБ), нужен .NET 8 Desktop Runtime;
* `fo-cli-win-x64/fo.exe` — консольная версия.

GitHub Actions (`.github/workflows/build.yml`) прогоняет тесты на Windows и публикует сборки как артефакт.
Подробнее — [docs/BUILD.md](docs/BUILD.md).

C# 12, .NET 8, WPF (MVVM без сторонних фреймворков), SQLite (Microsoft.Data.Sqlite), PdfPig (текст PDF), xUnit.
Ядро (`FileOrganizer.Core`) кроссплатформенное и полностью покрыто тестами; интерфейс — тонкий слой над ним.
