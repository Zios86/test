# DION Meeting Assistant

Windows-приложение для локальной стенографии ВКС DION, подготовки протокола и диагностики качества аудио/распознавания.

Текущая рабочая версия: **0.6 Quality**.

## Для человека

- Последний релиз: `v0.6-quality`.
- Portable EXE содержит offline Whisper `small` и не требует облачного STT.
- Основной режим: системный звук Windows через WASAPI Loopback + отдельный микрофон пользователя.

## Для Claude, ChatGPT, Codex и других ИИ

Не начинайте работу с полного сканирования репозитория.

1. Прочитайте `AGENTS.md` или `CLAUDE.md`.
2. Откройте `docs/PROJECT_MAP.md`.
3. Затем читайте только документ и модуль, относящиеся к задаче.
4. После любого изменения обновите документацию по правилам `docs/DOCUMENTATION_POLICY.md`.

`docs/` является **единой системой истины** для знаний о проекте. AI-специфичные файлы содержат только короткие инструкции и ссылки на эту базу.

## Важная особенность этой ветки

Ветка `dion-exe-build` сейчас является release/build-веткой. Базовый исходник восстанавливается из частей в `dion-portable/`, после чего применяются патчи:

- `dion-hotfix/apply_051.py` — исправления стабильности аудио 0.5.1;
- `dion-quality/apply_060.py` — улучшения распознавания 0.6;
- `.github/workflows/build-dion-portable.yml` — восстановление проекта, применение патчей, встраивание offline-моделей, PyInstaller, self-test и публикация Release.

Логическая карта восстановленного Python-проекта находится в `docs/PROJECT_MAP.md`.
