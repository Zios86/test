## Сделано сверх MVP

* Анализ содержимого документов (TXT, DOCX, XLSX, PPTX, ODT, ODS, ODP, RTF, PDF; кодировки UTF‑8/UTF‑16/Windows‑1251).
* ИИ‑классификация через подключаемый интерфейс, локальная Ollama, согласие на внешний сервис.
* Интеллектуальное переименование: анализ названий и шаблоны «Дата_Название», «Проект_Тип_Дата», «Клиент_Документ_Год».
* Проектные группы, похожие папки (объединение с проверкой конфликтов), «Возможно лежат не там», временные файлы,
  похожие версии документов со сравнением текста.
* Визуальный конструктор правил, профили, исключения, настраиваемые типы файлов.
* Папки «Разобрать» (Inbox) с периодической проверкой, виртуальные теги, поиск по содержимому.
* Восстановление после сбоя, «Восстановить состояние до…», «Удалить окончательно», Корзина Windows как опция.
* Консольная версия `fo`.

## Дальше

* Похожие изображения: perceptual hash (dHash/pHash) с декодированием через WIC; группы «оригинал / уменьшенная копия /
  копия из WhatsApp».
* Автоматические сценарии: запуск «Разобрать Загрузки» по расписанию (Планировщик заданий) с уведомлением —
  по‑прежнему только предложения, без автоматического применения.
* Различия в документах построчно (diff) и предпросмотр изображений рядом.
* Метаданные EXIF (дата съёмки) для раскладки фото по годам/месяцам.
* Инсталлятор MSIX и автообновление.
* Локализация интерфейса (сейчас — русский).
