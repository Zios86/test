# Полевые проверки 1.0.1

Проведите три реальные DION-встречи длительностью 15, 60 и 120 минут. Для каждой встречи сохраните папку сеанса, выполните послевстречную обработку, затем запустите:

```powershell
python .\field_validate.py "C:\путь\к\сеансу" --expected-minutes 15
python .\field_validate.py "C:\путь\к\сеансу" --expected-minutes 60
python .\field_validate.py "C:\путь\к\сеансу" --expected-minutes 120
```

Сценарий проверяет читаемость и длительность WAV, наличие live-стенограммы, синхронность двух дорожек и комплект результата post-processing. В папке встречи создаётся отчёт `field_validation_<длительность>m.json`.

Релизный критерий: все обязательные проверки имеют `passed: true`. Отсутствие микрофонной дорожки допустимо, если микрофон не выбирался. Акустическую точность и корректность имён спикеров дополнительно оценивает человек по контрольным фрагментам начала, середины и конца записи.
